# 后续需求

## 公司与用工关系辅助识别

状态：已记录，尚未实现，不影响现有正文证据规则。当前 employmentType=unknown 表示缺乏足够证据，不能据此判为企业直招。

建议分开表达两个事实：发布公司的业务／服务商线索，以及这个具体岗位的劳动合同主体、驻场方式和用工关系。不能把某公司发布的所有岗位统一判为外包。

分阶段方案：

1. 提供使用者可维护的公司／别名线索表，支持全称、品牌名和人工修正。条目包含来源、核对日期、置信度和备注；公司线索与岗位判定分别保存。公共模板使用虚构数据，真实名录经核对后再决定是否分享。
2. 结合 JD 中“签约主体”“服务客户”“驻场”等上下文证据，生成“可能为技术服务商岗位、需确认签约关系”标签，不把弱线索改写为确定事实。
3. 可选 LLM 提取原文证据并辅助别名归一，保留不确定状态。LLM 不能仅凭公司名或常识猜测实际合同关系，也不能代替名录来源和人工核对。

不要求先接 LLM 才能实现第一阶段。名录不应散落硬编码在爬虫中，且需要避免同名、简称、集团子公司和品牌名误匹配。
