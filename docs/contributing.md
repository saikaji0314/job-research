# 开发文档与公开内容约定

本仓库按通用工具维护。文档面向未来使用者和贡献者，说明产品行为、工程决策和可复现验证。

## 适合随源码公开的内容

- README：用途、功能状态、环境要求、安装与使用方法、通用配置说明和已知限制。
- 设计文档：模块边界、数据字段、筛选语义、恢复机制、平台适配方法。
- 实施计划：里程碑、待办与验收标准；保持简洁并更新已完成状态。
- 开发说明：环境配置、测试命令、虚构或脱敏样例、贡献约定。尚未实现的命令不写成可执行教程。
- 决策记录：重要方案的原因和取舍，例如为何分离采集与筛选；不粘贴完整聊天过程。
- 上游出处、逐文件复用及许可声明、依赖与版本信息。
- AGENTS.md：与项目相关的通用开发约定，不包含维护者个人画像。

## 仅留在本机或仓库外的内容

- 真实使用者的姓名、学历、经历、简历、目标城市、薪资期望、求职计划和对话记录。
- 个人环境的绝对路径、账号、密钥、Cookie、浏览器 Profile、验证截图和含会话数据的日志。
- 实际采集数据库、导出结果、第三方个人信息及未脱敏页面／接口响应。
- 临时调试流水、逐轮聊天摘要和个人学习评价。工程结论提炼成通用文档后再纳入仓库。

个人条件使用 `config/*.local.json`，本地数据使用被忽略的运行目录。公共模板用空值表示未设置；文档示例和测试数据需虚构或脱敏。记录 Git 变更时检查暂存内容，不能只删除当前文件而忽略待公开的提交历史。
